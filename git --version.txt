| Command         | Purpose               |
| --------------- | --------------------- |
| `git init`      | Initialize repository |
| `git add .`     | Add files             |
| `git commit -m` | Save changes          |
| `git push`      | Upload code           |
| `git pull`      | Download latest code  |
| `git branch`    | Create/check branch   |
| `git checkout`  | Switch branch         |
| `git merge`     | Merge branches        |
